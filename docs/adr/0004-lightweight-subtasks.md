# 子任务是轻量检查项，不复用卡片模型

子任务只有文字、完成、完成时间、组内顺序；不能挂正文或动作，也不能再嵌套。全部勾上不会自动勾父卡——机器只负责显示 `n/m` 并高亮，勾父卡始终由人触发。

**考虑过的方案**：复用卡片表加 `parent_id`，让子任务成为完整卡片。否决原因：递归会让渲染、拖拽、统计、折叠状态全部变成树操作，而终端宽度经不起多级缩进。真正需要挂动作的"子任务"应该被拆成同组内并列的卡片。

**更新（后续决定）**：卡片正面改为直接外显子任务清单（`n/m` 仍保留在第二行），并有子任务时不再显示正文预览——「只显示进度」这一条不再成立。其余结论不变：不嵌套、不挂动作/正文、不自动勾父卡。
