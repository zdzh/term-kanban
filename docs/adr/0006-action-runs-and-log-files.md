# 动作执行统一记账为「运行记录 + 日志文件」，TUI 呈现为让出界面

点动作时 core 立刻建一条运行记录（启动时间、退出码、完整输出落到日志文件），这层与前端无关。TUI 的呈现方式是暂时收起界面、把终端交给命令（输出原样可见、`ssh` 这类交互程序也能用），跑完回车返回；动作上带一个「需要终端」开关，默认不走让出界面。

分开的理由：将来 Web 版无法"把界面让出去"，浏览器只能后台跑并读输出，所以记账形状必须现在就按后台模型设计，而呈现方式留给各前端自己决定。

**安全约束**：Web 版若暴露动作执行，必须只绑 `127.0.0.1` 并要求 token——一个能跑 shell 的 HTTP 接口就是 RCE。
