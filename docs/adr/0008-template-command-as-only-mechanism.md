# 分组按钮与钩子都只是「模板命令」，不内置任何具体工具

新增的能力只有一个机制：带变量的命令模板（`{card_id}` `{slug}` `{repo}` `{worktree}` `{branch}` …）。它挂在三处——卡片动作（已有）、分组按钮（组 → 组内所有卡）、钩子（生命周期事件 → 卡）。「跳转到 agent」不是独立功能，而是分组按钮的一种配置：`open = "cmux {worktree}"` 换成 `codex {worktree}` 或 `code {worktree}` 即可，代码里不出现任何工具名。

**考虑过的方案**：内置 cmux 集成、内置 codex 集成。否决原因：每接一个工具就要改一次代码并重新编译，而用户明确要求"仅通过修改配置实现"。代价是模板错误只能在运行时报出来——因此在保存配置时就先拿假变量试渲染一遍，把拼错的变量挡在门外。

**安全边界**：拼进 shell 的值一律单引号转义；`{title}` 是自由文本，只允许用于显示，出现在命令里会直接报错（要引用标题请用 `{slug}`）。
