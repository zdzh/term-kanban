# 分组即列，「完成」是卡片上的二值勾选，不做状态列

看板的横向容器是**分组**（工作/生活/…），不承载进度；进度只有卡片上唯一的二值「完成」，由勾选切换并写入完成时间，取消勾选即清空。没有「进行中」——需要表达推进过程时用子任务。

**考虑过的方案**：① 列即状态（待办/进行中/完成）；② 二维——列是项目、行是状态，拖拽分两种手势。否决原因：②在终端里二维拖拽极易拖错且代码复杂度远超收益；①与"按项目分组"的需求冲突。代价：看板上没有「进行中」这个中间态。

**相关规则**：每个分组内部被分隔线切成未完成段（手动排序）与已完成段（按完成时间倒序，拖拽改不了顺序）；拖拽不能跨过分隔线，改完成状态只能用勾选；新卡与取消勾选的卡都追加到未完成段末尾。
